1. 가장 많이 쓰는 3가지 상황

상황 A. AI(클로드 코드)에게 화면을 시킬 때
가장 흔한 경우 · 소요 30초
  1. 모음집을 엽니다.
  2. 맨 위 조립기에서 ①콘텐츠(예: 뷰티 상세페이지) ②레이아웃(모듈러 그리드) ③디자인시스템(Toss)을 고릅니다.
  3. 탭을 AI 프롬프트로 두고 📋 복사.
  4. 클로드 코드에 붙여넣고 엔터. 끝.
왜 좋은가 섹션 순서(실제 사이트 조사분) + 색·폰트 토큰 + 반응형·이미지·접근성 규칙이 한 덩어리로 들어가서, AI가 임의로 만들지 않습니다.
상황 B. 프로젝트에 규칙을 심어둘 때
한 번만 해두면 계속 적용 · 소요 1분
  1. 모음집 조립기에서 쓸 디자인 시스템을 고릅니다.
  2. 탭을 CLAUDE.md로 바꿉니다.
  3. ⬇ 파일로 저장 → CLAUDE.md 파일이 받아집니다.
  4. 그 파일을 프로젝트 폴더 최상단에 넣습니다.
  5. 이제 그 폴더에서 클로드 코드를 쓰면 매번 복사할 필요 없이 규칙이 자동 적용됩니다.
같이 저장하면 좋은 것 탭을 CSS 토큰으로 바꿔 design-tokens.css도 받아 프로젝트에 넣어두면, 코드에서 var(--bg-primary)로 바로 씁니다.
상황 C. 고객이 브랜드 색을 줬을 때
숨고·외주 견적에 특히 유용 · 소요 2분
  1. 조립기를 엽니다.
  2. 브랜드 색에 고객이 준 HEX를 붙여넣습니다 (예: #2E7D6B). → 램프가 자동 생성됩니다.
  3. 중립색 온도 · 폰트 · 모서리 · 밀도를 취향에 맞게 조절 (오른쪽에서 즉시 확인).
  4. 상단 ⚡ 이 시스템으로 페이지 만들기 클릭.
  5. 생성기로 넘어가면서 ★ 내가 조립한 시스템이 자동 선택됩니다. 콘텐츠·레이아웃만 고르면 페이지 완성.
  6. ⬇ HTML 저장으로 파일을 받아 고객에게 보냅니다.

4. 자주 묻는 것

셋 중 뭘 먼저 열어야 하나요?
모음집입니다. 대부분의 경우 여기서 프롬프트만 복사하면 끝납니다. 색을 새로 만들어야 할 때만 조립기, 결과 파일이 필요할 때만 생성기로 갑니다.
내가 추가한 규칙은 어디에 저장되나요?
브라우저에 저장되어 다음에 열어도 유지됩니다. 다른 PC에서는 보이지 않으니, 중요한 규칙은 CLAUDE.md로 저장해 프로젝트에 넣어두세요.
조립기에서 만든 시스템이 생성기에 안 보입니다.
조립기에서 저장을 누르거나 ⚡ 이 시스템으로 페이지 만들기로 이동해야 반영됩니다. 같은 브라우저에서 열어야 합니다.
폰트가 이상하게 보입니다.
웹폰트를 인터넷에서 받아오므로 온라인 상태여야 제대로 보입니다. 오프라인이면 시스템 기본 폰트로 대체됩니다.
디자인 시스템을 더 추가하고 싶습니다.
조립기로 만들어 저장하면 생성기에서 쓸 수 있습니다. 모음집 카드로 영구 등록하려면 파일의 SYSTEMS 배열에 항목을 추가하면 됩니다.
지키는 원칙 보라·바이올렛 강조색, 왼쪽에 굵은 선이 붙은 인용 카드, 이모지 남발은 생성형 AI 티가 나는 패턴입니다. 이런 패턴은 규칙에서 금지로 넣어두었습니다. 프롬프트에도 자동 포함됩니다.
