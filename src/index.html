에셋 전체 보기

SVG 스프라이트, 개별 파일, React 컴포넌트, CSS로 내보냅니다. 선 굵기와 끝처리는 정한 시스템을 따릅니다.

쓰는 순서

01
CHOOSE
무엇을 만들지(콘텐츠), 어떤 구조로(레이아웃), 어떤 톤으로(디자인 시스템)를 정합니다.
02
EXPORT
AI 프롬프트, CLAUDE.md, CSS 토큰, 컴포넌트 CSS를 복사하거나 파일로 저장합니다.
03
BUILD
AI에 붙여넣거나 생성기에서 완성된 HTML을 받습니다.

안에 든 화면

모음집 디자인 시스템, 레이아웃, 콘텐츠 구조, 제작 규칙을 보관합니다. 맨 위 조립기에서 프롬프트와 토큰을 한 번에 뽑습니다. 열기 조립기 브랜드 색 하나로 50~950 램프를 만듭니다. 폰트, 모서리, 밀도까지 정해 나만의 시스템이 됩니다. 색으로 만들기 생성기 제품이나 병원 정보를 붙여넣고 콘텐츠, 레이아웃, 시스템을 정합니다. 실제 동작하는 HTML이 나옵니다. 페이지 만들기 사용설명서 상황별 사용법, 화면마다 어떤 버튼이 무엇을 하는지, 이미지 처리 방법, 자주 묻는 질문을 담았습니다. 읽기
한 파일, 빌드 없음, 인터넷은 웹폰트 로딩에만 씁니다
