레이아웃 레퍼런스 Layout Patterns

구조 뼈대 모음. 카드를 클릭하면 CLI(클로드 코드)에 바로 붙여넣을 프롬프트가 복사됩니다. 여기에 시스템 상세의 "AI 프롬프트"를 이어 붙이면 구조+디자인이 한 번에 지정돼요.

콘텐츠별 화면 구조 Page Structures

실제 사이트(올리브영·Glossier·Linear·Apple·Zillow 등) 기준으로 조사한 섹션 순서입니다. 클릭하면 화면 구조가 자세히 펼쳐집니다.

제작 규칙 Rules

모든 산출물에 공통으로 적용하는 규칙. 조립기 프롬프트에 자동으로 포함되며, 아래 버튼으로 규칙만 따로 복사해 CLAUDE.md 등에 넣을 수도 있어요.

📐 반응형

  • 여백·타이포는 vw + clamp() 사용
  • 컨테이너 width: min(1200px, 92vw)
  • 브레이크포인트 1280 / 1024 / 768 / 480
  • 768 미만에서 모든 다단은 1열로
  • 터치 타겟 최소 44×44px

🖼 이미지

  • WebP 저장, 200KB 이하
  • width:100% + aspect-ratio로 비율 고정
  • 같은 줄의 이미지는 비율 통일
  • 텍스트 얹힐 자리는 비워둘 것

♿ 접근성

  • focus-visible 2px 링 필수
  • 본문 대비 4.5:1 이상 (AA)
  • 아이콘 버튼은 aria-label
  • prefers-reduced-motion 대응

🚫 금지 (AI 슬롭)

  • 보라/바이올럿 강조색 금지
  • border-left 굵은 인용카드 금지
  • 보라→핑크 그라디언트 히어로 금지
  • 이모지 남발 콜아웃 금지
  • 임의 색·폰트 사용 금지 (토큰만)
